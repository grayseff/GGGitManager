# GGGitManager

A small GTK4 desktop application for managing multiple Git repositories.

GGGitManager scans your home directory for Git repositories and provides a
simple graphical interface for common Git operations.

### Personal note
This project wasn't quite "vibe coded" but strongly "AI tutored" to get the API's and management correct

## Features

- Automatically discovers Git repositories under your home directory
- Shows repository status
- Add repositories
- Stage and commit changes
- Pull from upstream
- Push to upstream
- Refresh repository status
- GTK4 desktop interface
- Installs as a normal desktop application with a custom icon

## Requirements

- GTK4
- Clang
- Make
- Git
